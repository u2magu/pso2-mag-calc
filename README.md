# PSO2 マグ育成 計算ツール

PSO2（EP6時点）のマグ育成を計算する非公式ファンツールです。

## 機能

- **現在のマグ入力** — 7ステータスのLv入力＋極振りプリセット
- **目標まで何個？** — アイテムと目標Lvから必要個数を計算
- **何個でどこまで？** — 個数から到達Lvと「Lv200まであと何個」を表示
- **育成プラン** — 複数アイテムを順番に与えたときの結果をシミュレーション
- **アイテム早見表** — 各アイテムの上昇・下降値
- **テーマカラー** — ブルー / ホワイト / グリーン / オレンジ / ピンク / パープル / ダーク（右上のプルダウン、選択は保存されます）

## 使い方

`index.html` をブラウザで開いてください。

公開版: https://u2magu.github.io/pso2-mag-calc/

## 計算仕様

- 支援Lv 0～49: 30pt/レベル
- 50～59: 70pt/レベル
- 60～69: 90pt/レベル
- 70～79: 110pt/レベル
- 80～89: 130pt/レベル
- 90～99: 150pt/レベル
- 100～109: 180pt/レベル
- 110～119: 210pt/レベル
- 120～199: 240pt/レベル
- Lv200までの累計: 30,100pt

主なアイテム効果:

- フードデバイスミニ: 各 +60pt
- フードデバイス（通常）: 各 +720pt
- カスタムディスク: 技量 +150pt / 防御 -3pt
- ディスク: 技量 +30pt / 防御 -3pt
- ★9武器: 攻撃 +128pt / 技量 +10pt / 対応防御 -30pt

## 開発

```bash
node test.js      # 計算ロジックのテスト
node build.js     # 単体HTML（pso2-mag-calc-standalone.html）を生成
node serve.js     # ローカル確認用サーバー（http://localhost:8787/）
```
